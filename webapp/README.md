# HealNexus Frontend

React 19 + Vite + TypeScript application for HealNexus.

See the root [README.md](../README.md) for problem statement, architecture, APIs, secrets policy, and full setup.

```bash
copy .env.example .env
npm install
npm run dev
```

Requires Node.js 20+. Default URL: http://127.0.0.1:5173

Do not put `EXA_API_KEY` or `OPENROUTER_API_KEY` in this folder.
